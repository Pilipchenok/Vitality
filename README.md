# Vitality

Vitality - Десктопное приложение для мониторинга ресурсов локальной системы (CPU, RAM, диск, температура). Написано на Go с использованием Wails v3 и JavaScript (Chart.js).

![Скриншот интерфейса](images/screenshot.png)

## Функциональность

- **Двухоконный интерфейс:**
  - **Виджет (250x320):** безрамочное поповер-окно возле системного трея. Автоматически скрывается при потере фокуса.
  - **Дашборд (1024x768, min 900x600):** полноразмерное окно с системной рамкой (светофоры macOS / кнопки Windows), графиками ресурсов и журналом событий.
- **Мониторинг ресурсов:**
  - Загрузка CPU (%) и температура процессора (°C).
  - Использование RAM (%) и диска (%).
  - Интервал сбора метрик — 2 секунды.
- **Аналитика:**
  - Графики загрузки с временными окнами 5, 15 и 30 минут.
  - Расчет изменения показателей за 5 минут.
  - Оценка Node Health Score.
  - Журнал критических событий (перегрев, высокая нагрузка).

## Архитектура и стек

- **Backend (Go):** сбор показателей через `gopsutil/v3`, хранение истории в кольцевом буфере в памяти (`sync.Mutex`).
- **Транспорт (REST API):** локальный `http.Handler` внутри Wails для взаимодействия с фронтендом через `fetch`.
- **Frontend (JS / HTML / CSS):** без фронтенд-фреймворков, отрисовка графиков на Canvas через `Chart.js 4.x`.
- **GUI:** Wails v3 (`beta.6`), системный трей, раздельное управление двумя окнами.

### Установка и запуск

## Скачать готовый релиз

1. Перейдите в раздел [Releases](../../releases).
2. Скачайте файл `Vitality.dmg`.
3. Откройте `.dmg` и перетащите `Vitality` в папку `Applications`.

## Сборка из исходников

## Требования
- Go 1.21+
- Node.js и npm
- Зависимости Wails v3 (Cgo, WebKitGTK / WebView2)

# Клонировать репозиторий
```bash
git clone https://github.com/Pilipchenok/Vitality.git
cd Vitality
```

# Собрать frontend
```bash
cd frontend
npm install
npm run build
cd ..
```

# Запустить приложение
```bash
go run .
```

### Для пользователей Linux (Ubuntu/Debian)

Поскольку в Linux существует множество различных графических оболочек, приложение использует системный движок **WebKitGTK** для отрисовки интерфейса. 

Если при запуске ничего не происходит или система просит зависимости, установите их одной командой в терминале:

```bash
sudo apt update
sudo apt install -y libwebkit2gtk-4.1-0
```


### Для пользователей macOS

Если MacOS блокирует открытие приложения, переместите Vitality в папку **Applications** и выполните команду:

```bash
sudo xattr -rd com.apple.quarantine /Applications/Vitality.app
```
